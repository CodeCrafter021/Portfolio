# Saini Amitkumar — Portfolio

A responsive personal portfolio built with React and Vite. It showcases my full-stack development work, skills, experience, and certificates.

## Run locally

```sh
npm install
npm run dev
```

## Build and lint

```sh
npm run build
npm run lint
```

## Features

- Responsive floating navigation and light/dark theme toggle
- Animated hero illustration with reduced-motion support
- About, skills, experience, projects, certificates, resume, and contact sections
- Contact form that prepares an email in your default mail app
